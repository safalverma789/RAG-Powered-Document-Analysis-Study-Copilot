# AURA RAG Study Copilot

Autonomous Understanding & Retrieval Architecture built with FastAPI, ChromaDB, Google Gemini, and React + Vite.

---

## 🚀 Single Commands to Start the Project

You can run the entire full stack (FastAPI backend + React frontend + Browser auto-open) with **any single command** below:

### Option 1 (Recommended — Double click or terminal):
In PowerShell or CMD:
```bat
.\start.bat
```
*(Or simply double-click `start.bat` in Windows File Explorer)*

### Option 2 (Single terminal with unified live logs):
```powershell
backend\.venv\Scripts\python.exe run.py
```
*(Runs both servers in your current terminal; press `Ctrl+C` to stop both)*

### Option 3 (via npm):
```powershell
npm.cmd start
```

---

## 🛑 Single Command to Stop the Project

To stop both backend (port 8000) and frontend (port 5173):
```bat
.\stop.bat
```
*(Or double-click `stop.bat` in Windows File Explorer)*
